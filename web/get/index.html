Android

Install the app directly. No Play Store needed.

Download the Android app
  1. Open the downloaded file.
  2. If asked, allow installs from your browser, then tap Install.
  3. If Play Protect asks about an unknown developer, tap More details, then Install anyway.

iPhone

Get the native app through Apple's TestFlight. It's free and takes a minute.

Get the iPhone app
  1. Tap the button, then install TestFlight from the App Store if asked.
  2. Back on the TestFlight page, tap Accept, then Install.
Or use the web app
Web app: open it in Safari, tap Share, then Add to Home Screen.
